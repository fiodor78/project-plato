# Plato profile — corpus and attribution policy

**Status:** Phase 0 draft

The Plato profile preserves the full historical Corpus Platonicum in scope review rather than equating the corpus with only works accepted as authentic by modern scholarship.

Modern attribution/authenticity assessment belongs to CUSTODIAN metadata and is not automatically part of PLATO's world.

The working profile-specific classification system is:

| Code | Meaning |
|---|---|
| A | strongly accepted as Platonic |
| B | disputed |
| C | probably spurious |
| D | pseudo-Platonic |

This A–D system is a **profile rule**, not a Thinker Core rule.

The final classification of individual works will be established during Corpus Catalog research and will cite its scholarly basis.
