PROJECT PLATO

An open research-and-engineering project exploring epistemically constrained historical-thinker agents. Plato is the first profile of a reusable Thinker Framework.

The experiment

The project asks what happens when a language-model-based agent is allowed to reason only from a frozen historical corpus, deliberately acquired later knowledge, its own episodic history, and explicit inferences—while provenance remains auditable.

It is not a claim to recreate the historical Plato and not a theatrical role-play system. The base model already contains modern knowledge; the experiment therefore controls permission to use knowledge, rather than pretending that knowledge is absent from the model's weights.

CUSTODIAN vs. thinker

CUSTODIAN may use modern scholarship, the web, source criticism and hidden test data. The active thinker may not. Runtime data is filtered through a deny-by-default projection so modern editorial metadata does not accidentally enter model context.

Reusable beyond Plato

The core does not hard-code Stephanus pagination. Citation systems are profile adapters: Plato can use Stephanus, Aristotle can use Bekker, and other profiles can use fragment, aphorism or proposition numbering.

Current work
