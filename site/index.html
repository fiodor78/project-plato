Phase 1 — Corpus Platonicum catalog and attribution model

PROJECT PLATO

An open research-and-engineering project exploring whether a language-model-based agent can function as an epistemically constrained historical thinker. Plato is the first profile of a reusable Thinker Framework.

The experiment

The project asks what happens when an agent reasons from a controlled historical corpus, explicitly acquired later knowledge, its own episodic history and traceable inferences—while the origin of that knowledge remains auditable.

It is not an attempt to recreate the historical Plato, and it is not ordinary role-play. The base language model inevitably contains modern latent knowledge; PROJECT PLATO therefore controls permission to use knowledge, rather than pretending that forbidden knowledge is absent from model weights.

How PLATO will be used

The intended user experience is a normal conversation: interlocutor ↔ PLATO. CUSTODIAN does not mediate each turn. Instead it prepares and audits the environment: corpus, retrieval, provenance, memory policy, tests and epistemic boundaries.

Interlocutor ↔ PLATO
                  │
                  ├── ORIGINAL corpus
                  ├── ACQUIRED knowledge
                  ├── EPISODIC memory
                  ├── INFERENCE
                  └── provenance / audit

CUSTODIAN prepares, verifies and audits the environment.

Read-only knowledge grounded in a frozen corpus release.
ACQUIRED
Information communicated after the instance begins.
EPISODIC
Instance-specific remembered interactions and events.
INFERENCE
Conclusions derived from admissible sources.

Language engine

The language model is a replaceable reasoning and generation engine. It is not PLATO's corpus or long-term memory.

The Thinker Core uses a provider-neutral LanguageEngine boundary. The preferred first production gateway is OpenRouter, while direct-provider and mock adapters remain possible.

For frozen experimental baselines, automatic model selection is not allowed. The requested model, routing policy, fallback policy and relevant inference parameters must be pinned and audited. Actual provider/model execution metadata, token use and cost remain CUSTODIAN/runtime metadata rather than thinker-visible knowledge.

CUSTODIAN vs. thinker

CUSTODIAN may use modern scholarship, the web, source criticism and hidden test data. The active thinker may not. Runtime data is filtered through a deny-by-default projection so modern editorial metadata, technical IDs, source URLs and hidden authenticity judgments do not accidentally enter model context.

Current Phase 1 work

Historical scope
Attestation-based Corpus Platonicum scope and taxonomy are defined.
Epistles
All thirteen canonical letters are individually mapped and now have provisional work-specific authenticity assessments; Letter X preserves the Aristodemus/Aristodorus variant.
Epigrammata
The current 23-member Greek Anthology inventory is explicitly provisional. A validated 31-row Page/Massimo transmission crosswalk and deterministic migration-plan gate now separate matches, missing texts, unresolved identity conflicts and Plato Junior/homonymy exclusions. Pelucchi 2026 still has to complete the 37-text scope before catalog v0.1.5 is authorized.
Authenticity
A/B/C/D assessments are versioned, evidence-based CUSTODIAN assertions rather than corpus identity. Canonical and extra-canonical Epistle coverage is complete; the remaining authenticity backlog is the individual epigram corpus.

Production Greek-text ingestion has not yet begun. Phase 1 is still completing the historical catalog, including the epigram transmission crosswalk, attribution coverage and work-code registry before Phase 2 source-edition selection and deterministic ingestion. The number 23 must not be read as the complete historical Plato-epigram corpus.

Reusable beyond Plato

The core does not hard-code Stephanus pagination or Plato-specific assumptions. Citation systems are profile adapters: Plato can use Stephanus, Aristotle can use Bekker, and other profiles can use fragment, aphorism or proposition numbering. Each thinker receives an isolated corpus, memory and experiment lineage.
