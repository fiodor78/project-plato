# EPISTLES AUTHENTICITY 0001 — high-confidence rejections

**Status:** Phase 1 working assessment note

This note begins work-specific authenticity assessment for the thirteen Epistles. It deliberately starts only with cases where the evidence is unusually strong.

## Epistle I — D

**Assessment:** pseudo-Platonic / overwhelmingly rejected.

Reasons include:

- Bury rejects the letter and points to historical/narrative conflicts with the stronger Sicilian tradition.
- Modern surveys of the authenticity debate commonly treat Letter I as one of the principal exceptions even where substantial portions of the letter collection are defended.

This is an authorship judgment, not a reason to remove Letter I from the historical catalog.

## Epistle XII — D

**Assessment:** pseudo-Platonic / overwhelmingly rejected.

Reasons include:

- the manuscript tradition uniquely preserves an explicit denial of Platonic authorship after Letter XII;
- Bury treats the letter as certainly spurious and connects it to pseudo-Pythagorean/Ocellus material;
- modern reference scholarship continues to describe the Twelfth Letter as pseudo-Platonic.

## Deliberately not yet classified

Letters II–XI and XIII remain ungraded in this tranche, including Letter VII.

The project will not infer their classifications from a single global judgment about the Epistles. Each must receive a work-specific evidence record.
