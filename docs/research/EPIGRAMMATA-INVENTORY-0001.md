# EPIGRAMMATA INVENTORY 0001 — individual Greek Anthology attributions

**Status:** Phase 1 provisional member inventory

## Purpose

Replace the single collection-level `Epigrammata` placeholder with individually addressable anthology members without making any claim that Plato authored them.

## Current source

Anthologia Graeca Project, Plato author page:
https://anthologiagraeca.org/authors/51/

The current digital author index lists 23 Greek Anthology items under Plato:

- AP 5.78, 5.79, 5.80
- AP 6.1, 6.43
- AP 7.99, 7.100, 7.256, 7.259, 7.265, 7.268, 7.269, 7.669, 7.670
- AP 9.3, 9.39, 9.51, 9.506, 9.747, 9.823, 9.826
- AP 16.13, 16.248

These are now represented as child/member records beneath `TH.PLATO.CAT.EPIGRAMMATA`.

## Important limitation

This is an **attribution inventory**, not an authenticity inventory.

The project must still review:

- competing author attributions;
- duplicate textual traditions;
- whether all 23 items belong to the same historical Plato-ascription stratum;
- editorial differences among Bergk, Paton, Page and later scholarship;
- whether any additional Plato-attributed epigrams outside this digital author index need catalog inclusion.

## Known competing attribution

AP 16.248 is also transmitted with an attribution to Antipater. The catalog records this as a competing attribution rather than flattening the evidence.

## Runtime consequence

All individual epigrams remain `PENDING_REVIEW` and `CUSTODIAN_ONLY`.

None enters PLATO's ORIGINAL runtime corpus merely by being historically attributed to Plato.
