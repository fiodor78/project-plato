# CORE AUTHENTIC DIALOGUES 0001 — A-classification tranche

**Status:** Phase 1 provisional assessment

PROJECT PLATO assigns **A — strongly accepted as Platonic** to 26 core dialogues for which current reference scholarship does not present a significant live authorship controversy.

## A-classified works

Euthyphro; Apology; Crito; Phaedo; Cratylus; Theaetetus; Sophist; Statesman; Parmenides; Philebus; Symposium; Phaedrus; Charmides; Laches; Lysis; Euthydemus; Protagoras; Gorgias; Meno; Hippias Minor; Ion; Menexenus; Republic; Timaeus; Critias; Laws.

## Evidence logic

The principal cross-check uses:

- the Internet Encyclopedia of Philosophy's chronology of the accepted dialogues, which explicitly separates spuria and dubia; and
- Malcolm Schofield's Routledge Encyclopedia treatment of authenticity, which isolates the principal live disputed cases.

Additional work-specific support is recorded for Menexenus, Ion and Hippias Minor.

## Qualification

A means strong acceptance of Platonic authorship. It does **not** mean that chronology is settled, transmission is perfect, or every speech/character in a dialogue can be equated with Plato's own philosophical voice.
